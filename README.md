# Киноклуб Мелкомемья

Это демонстрационный проект интернет-сообщества друзей «Мелкомемье» и автора проекта. Сайт создан для удобного просмотра каталога фильмов.

## Основные принципы

1. Сайт полностью бесплатный и ничего не рекламирует.
2. Сайт принадлежит интернет-сообществу друзей «Мелкомемье», а также его автору.
3. Сайт вынужден обрабатывать данные Google Профиля для доступа к Google Sheets, чтобы загружать информацию из базы данных.
4. Остальная информация о людях, которая демонстрируется на сайте, разрешена этими людьми по умолчанию, так как она находится в эксель таблице проекта. Но при желании человек может попросить анонимизировать информацию о себе, обратившись лично к автору сайта.

## Что делает сайт

- показывает каталог фильмов;
- позволяет удобно искать и сортировать фильмы;
- помогает участникам добавлять записи в общую базу данных;
- показывает информацию о кинооценках и участниках;
- работает с Google Sheets как с общей базой данных проекта.

## Условия доступа

Сайт открыт для каждого человека, если нет специальных ограничений по техническим, правовым или организационным причинам. Главная цель проекта — сделать его максимально доступным и безвозмездным для пользователей, которые заинтересованы в общении и совместном участии киноклуба.

## Обработка данных Google

Для работы с общей базой данных сайт использует Google OAuth и Google Sheets. В связи с этим автоматически обрабатываются данные Google профиля, необходимые для доступа:

- почта;
- аватар профиля Google;
- никнейм пользователя.

Эти данные используются только для входа в сервис, идентификации пользователя в проекте и загрузки информации из Google Sheets. Сайт не собирает и не использует дополнительные личные данные пользователя без необходимости.

## Авторство и принадлежность

Проект является частью интернет-сообщества друзей «Мелкомемье» и создан при участии его автора. Сайт ориентирован на сообщество и демонстративную, дружескую среду, без коммерческой рекламы и каких-либо маркетинговых элементов.

## Технологии

- React
- TypeScript
- Vite
- Redux Toolkit
- Tailwind CSS
- Google OAuth
- Google Sheets API
- TMDB API (для данных о фильмах и изображениях)
- Кинопоиск API

## Структура проекта

- `src/` — клиентский интерфейс приложения;
- `src/components/` — переиспользуемые UI-компоненты;
- `src/pages/` — страницы проекта;
- `src/HooksExcelMovies/` — логика загрузки данных из Google Sheets;
- `src/HooksTMDB/` — работа с API TMDB;
- `functions/` — серверные обработчики и маршруты Cloudflare Pages;
- `worker/` — служебный слой для проксирования и интеграции.

## Примечание

Проект создан в демонстрационных и общественных целях. Он бесплатный, не содержит рекламы и рассчитан на использование внутри сообщества «Мелкомемье» и среди заинтересованных пользователей, которым доступ к проекту не ограничен.
